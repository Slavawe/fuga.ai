# MANIFEST: FUGA-1.2 — FineWeb-Edu как главный EN-домен (24.10.2026, сессия II)

## Задача пользователя
«FineWeb и FineWeb-Edu (HF), The Pile (EleutherAI), Common Crawl, Dolma —
возьми с них самое лучшее и обучи ИИ».

## Что взято и почему (бюджет машины: ~830-1200 pairs/s, 233GB диск)
- **FineWeb-Edu** (HuggingFaceFW/fineweb-edu, sample-10BT) — общий источник
  перечисленных корпусов это Common Crawl; FineWeb-Edu — его LLM-фильтр по
  образовательной ценности (score 1–5). Берём **score ≥ 3** (educational) —
  максимальная плотность качества на байт; The Pile / Dolma — шарды 2–3GB+,
  на бюджете ~85MB корпуса проигрывают по качеству/байт (принцип 15.10).
  FineWeb (без -Edu) — то же Crawl без edu-фильтра, поэтому выбор Edu.
- Загружено 2 шарда (000_00000, 001_00000 — 4.05GB, 1.455M доков, 100% en).
  Использовано 16,397 доков (запас сканирования есть — оба шарда на диске).
- **Вал FineWeb-Edu**: val_en_web_v12.bin (420KB, 72 дока, p=0.02 отбор).

## Корпус v1.2 (train_fuga1/build_corpus_v12.py)
- fuga12_train.jsonl — 17,517 доков, **85,780,000 B (~85.8 MB)**,
  SHA256 (16) = **3e6f8fa3ad054465**
- Домены (с оверсэмплингом малых): en_web 93.3% (FineWeb-Edu, маркер [EN]),
  code 4.0% (×2 локальный Rust/Py + russian-code, [CODE]), ru 1.1% (×4
  wiki/AGENTS/диалоги, [RU]), en 0.6% (×2 доки репо, [EN]).
- Оверсэмплинг — защита bilingual от вымывания при EN-web доминанте.
- Перемешивание: ПРОПОРЦИОНАЛЬНЫЙ планировщик (домен с минимальной выполненной
  долей бюджета) — round-robin v1.1 вымыл бы малые домены на 85MB.
- Потоковое чтение parquet батчами по 20K (to_pylist() на 1.4M строк = OOM).
- Вал (без маркеров): val_code/en/ru/en_web_v12.bin + val_all_v12.bin (665,804 B).

## ПЕРЕЗАПУСК (v2, решающая правка): оверсэмплинг усилен
- Прерванный прогон №1 (сохранён как runs/fuga_1_2_dilute_aborted/, лог и
  ckpt 500K/1M внутри): оверсэмплинг ru ×4 / code ×2 при en_web 96% → на 1M
  val_domains: en_web 0.3481 (учится), но **code 0.1162 / ru 0.1118** — малые
  домены вымываются (не «забывание», а свежая модель с рационом 93% EN-web:
  к 5M шагов ru получил бы ~55K пар против 375K у v1.1@1.5M).
- **Урок: доля домена в рационе = доля пар × шаги; держать АБСОЛЮТНЫЕ пары
  домена ≥ исторических уровней, не «долю потока».**
- v2 корпус: en_web ×1 (78.3%), code ×6 (10.2%), ru ×40 (9.3%), en ×4 (1.1%) —
  102,190,498 B, SHA256 (16) = a6634cd2a5693eeb. Целевые пары на 5M:
  en_web ~3.9M, code ~510K, ru ~465K — сопоставимо с v1.1 по малым доменам
  + 3.9M свежих EN-web пар (в 8 раз больше всего корпуса v1.1).
