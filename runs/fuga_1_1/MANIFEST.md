# MANIFEST: FUGA-1.1 — единое обучение с маркерами доменов (24.10.2026)

## Что это
Единый прогон «говорит (RU/EN) + пишет код» с ДВУМЯ улучшениями относительно
baseline Fuga-1.0 (runs/2026-10-15_baseline, fuga_1_0_step1500.fuga) —
каждое изолированно обосновано ранее:

1. **Cosine-decay LR** (Gary 17.10 фаза 2.1, пред-регистрация): lr_w(t) =
   lr_min + 0.5(lr_max−lr_min)(1+cos(πt/T)), T=1.5M, lr 0.05→0.005.
   Обоснование: decay-прогон 17.10 (runs/f1_pc_ab/decay_1m, T=1M) дал
   монотонную вал-кривую 0.3903→0.4566→0.4717 против осциллирующей baseline
   (размах 0.156, просадки) — критерий «монотонность» выполнен.
2. **Маркеры доменов [CODE]/[EN]/[RU]** (рычаг «фазовый curriculum + маркеры
   домена», Gary 16.10 п.1): каждый train-док корпуса v1.1 получает префикс
   домена ВНУТРИ JSON-значения; на декоде маркер задаётся сидом
   («[RU] текст», «[CODE] def …») — байтовый control-input.
   Предрегистрированный критерий v1.1 (Gary 16.10 п.6): на PY-сидах
   cyr% ≤ 30% И code% ≥ 5%.

## Конфиг прогона (одинаковый с baseline, кроме двух переменных выше)
- тренер: fuga1 train (== unified_gpu_train; единый бинарник 24.10)
- корпус: train_fuga1/corpus/fuga11_train.jsonl — 527 доков, 2,308,934 B,
  маркеры на всех 527 доках ([CODE]=481, [EN]=13, [RU]=33),

- вал (без маркеров): val_all_v11.bin 237,326 B (code/en/ru вал из тех же raw,

- max-steps 1,500,000; ctx=8; patch-ctx=8; batch=256
- λ-patch curriculum 0.4→0.1 (τ=500K) — как baseline
- lr-w 0.05, lr-decay-steps 1,500,000, lr-min 0.005 — НОВОЕ (baseline: фикс. 0.05)
- ckpt-every 250K, ВЕРСИОНИРОВАННЫЕ (fuga_1_1.fuga.step{N}.ckpt.fuga) — фикс
  15.10; выбор лучшего пост-фактум
- --threads 4 (параллельная подготовка пар, порядок сохранён) — ~830 pairs/s
  против 295 у baseline (GPU wgpu-канал)

## Скоркарта способностей @1.5M (capability_test, βm=0.3, сиды БЕЗ маркеров)
- **MB3 — все сиды 200B** (V2 на PY/EN-сиде «the model learns» обрывается 2–3B —
  V2-аттрактор стал менее монотонным; MB3 устойчив везде).
- **Доменное разделение в MB3**: RU-сиды cyr 97–99%; EN-сиды cyr **0.0**
  (чистая латиница, «storen_erestrendedpet_rorestennested…»); PY/RS —
  латиница с код-синтаксисом («…estrende(prinnensestedded», «…turnendened_ende_…();}e»).
  Средняя cyr по доменам: RU 79.0 / EN 49.1 / PY 0.0 / RS 39.3 (V2: 76/70/74/0).
- **Разнообразие**: средний top4% = **3.7 против 9.6 у baseline** (в 2.6 раза
  ниже сила аттрактора).
- Маркер-декоды (fuga1 chat): «[RU] …» → кириллический морфемный поток
  (пользов-/полен-/пор-); «[EN] …»/«[CODE] …» → латиница с код-знаками.
  Разделение RU vs не-RU чёткое; EN vs CODE на байтовом уровне не различаются
  (сходятся в один латинский бассейн — согласуется с диагностикой 16.10).
- **Предрегистрированный критерий v1.1 (cyr≤30% И code%≥5% на PY-сидах) —
  НЕ СДАН**: V2 обрывается на PY-сидах (критерий определён на V2-декоде),
  code% остаётся 0. Разделение домена появилось в MB3, но кодовой
  грамматики ещё нет — следующий фронт (Syntax Loss / Python-AST маска).

## Честные ограничения
- Уровень генерации — морфемно-связные потоки, НЕ грамматика (как и baseline);
  прогресс 1.1 — доменный контроль + стабильность + разнообразие.
- V2 на части код/EN-сидов даёт короткие обрывы — основным декодером становится
  MB3 (устойчив, макро-осознанный).
- Инцидент-митигация (hash-check корпуса в тренере) — НЕ входит в этот прогон,
  в очереди следующей сессии.
